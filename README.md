# Taller de vistas funcionales

Diagramas UML de componentes para los casos MediCare y EduManager.

## Entregables

- `MediCare_EduManager.vpp`: proyecto editable de Visual Paradigm con ambos diagramas.
- `MediCare_componentes.png`: responsabilidades y dependencias del caso de clínica.
- `EduManager_componentes.png`: responsabilidades y dependencias del caso académico.

Las dependencias están representadas con flechas discontinuas. En EduManager, la inscripción coordina componentes independientes para comprobar prerrequisitos, cupos y conflictos de horario.
